# PrepCampus

AI-powered placement preparation platform for engineering students and fresh graduates.

## 🚀 What is PrepCampus?

PrepCampus helps students prepare for campus placements through structured coding practice, aptitude preparation, company-specific mock tests and career-focused learning resources.

## 💻 What Students Can Practice

- Coding & DSA
- Quantitative Aptitude
- Logical Reasoning
- Verbal Ability
- Company-Specific Mock Tests
- Daily Coding Challenges
- Programming Challenges
- Placement Preparation

## 🏢 Company-Specific Preparation

Prepare for placement assessments from companies such as:

- TCS
- Accenture
- Capgemini
- Cognizant
- Infosys
- Wipro
